# SDK examples

Runnable scripts for the Python client (`pip install -e "sdk/python[dev]"`).

Needs a running Grounded LLM API (e.g. Compose with `TELEGRAM_AUTH_DISABLED=true`).

```bash
python sdk/python/examples/chat_basic.py
```

See [sdk/python/README.md](../README.md) and [QUICKSTART_SDK.md](../../../docs/en/QUICKSTART_SDK.md).
