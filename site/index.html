  • Redis caches — embedding vectors + semantic LLM responses; HTTP X-Cache: HIT|MISS
  • gRPC Retriever — Python :50051 for agents (grounded.rag.v1.Retriever)
  • LLM metrics — Prometheus llm_tokens_*, TTFT, latency on Go /metrics
  • Production hardening — fail-fast prod checks, Gunicorn RAG, Trivy, load smoke, tenant isolation
  • Hybrid retrieval — BM25 + dense + RRF; Chroma / Qdrant / pgvector
  • Quality gate — 99 retrieval eval cases in CI
  • Template packs — HR, IT Support, Legal FAQ

Quick start

git clone https://github.com/kantik001/grounded-llm.git
cd grounded-llm
cp .env.example .env
# Optional local LLM: LLM_PROVIDER=ollama + docker compose --profile ollama up -d --build
docker compose up -d --build

pip install -r conformance/requirements.txt
python -m conformance spec
